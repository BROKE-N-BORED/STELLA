# Stella audit task list — grouped by area, highest to lowest priority

The same 194 tasks as `stella-audit-task-list-123.md` (20 P0 / 62 P1 / 67 P2 / 45 P3,
447 findings covered), grouped by the part of Stella they touch. Groups are ordered by
their highest-priority task, and tasks inside a group run in priority order — the
T-number IS the rank, so work down a group in T-number order. Each entry is a summary;
the full Problem, Fix, and Done for a task live in the merged list under its T-number.
Generated 2026-11-13 from the 168-task merged list; updated 2026-11-13 for the
Audit #9 merge (194 tasks). Nothing here changes the merged list.
